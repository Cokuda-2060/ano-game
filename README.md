（1）制作アプリのタイトル
"あの"ゲーム

（2）制作アプリの説明（40文字程度）
地域によって呼び方が変わるけど、なぜかみんなルールは同じの手遊びゲームです。

（3）工夫した点・こだわった点
呼び方を変えられるようにした点と
指の画像で結果を表示するようにして、勝負を実際の指でやっている時と似たように表現しました。

（4）難しかった点
• プレイヤーと相手が順番に行動する「ターン制」の骨組み
「自分の指を決める ➔ コール（掛け声）を選ぶ ➔ 相手のターンに移る」という決まった順番（ステップ）通りにしか操作できない仕組みを作る必要がありました。
今がどの順番なのかを記録する「合図（フラグ）」を用意し、順番に合わせて画面上のボタン（指ボタン・コールボタン）を表示/非表示にするのに苦労しました。

• 1つのボタンに「自分のターン」と「相手のターン」の2つの役割を持たせる処理
「指ボタン（0〜2本）」は、自分の順番で指をあげる時にも、相手のコールに対して指をあげる時にも同じボタンを使ので、
「今はどっちのターンか？」を判別できるようにするif文が難しかったです。
